# Y700 五代 165 Hz 显示补丁

适用于 TB323FU 的 Baldur 面板。当前统一 Linux 7.2.6 通过 [`packages/kernel/patches/0174-drm-panel-nt36523-baldur-add-90-Hz-and-165-Hz-modes.patch`](../../../../packages/kernel/patches/0174-drm-panel-nt36523-baldur-add-90-Hz-and-165-Hz-modes.patch) 集成该修正，来源记录见 [PATCHES.md](../../../../packages/kernel/PATCHES.md)。构建统一内核时不再手工叠加本目录的旧编号补丁。

## 时序与已知问题

补丁加入厂商 `dtiming@5` 的 90 Hz 模式和真实 165 Hz 模式。165 Hz 保留 120 Hz 的水平时序，使用 Htotal 2244、Vtotal 3120 和 1155211 kHz 像素时钟，计算刷新率约为 164.99997 Hz。

90 Hz 偶发物理花屏仍需排查。Gamescope 的 EDID 时钟修正处理显示元数据，与面板时序是不同问题；当前状态统一记录在[五代已知问题](../../README.md#已知限制)。本补丁不用于四代面板。
